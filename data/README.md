# data/

存放示波器的本地产物：仪器配置（setup）导出、原始波形 CSV 等。

目录壳（本文件）纳入版本库，**目录内容一律不入库**——由 `.gitignore` 的
`data/*` + `!data/README.md` 保证，新增任何文件都会被自动忽略。

典型内容（均为本地环境/运行产物，勿手动提交）：

- `instruments.yaml` — 仪器连接登记表（IP、端口、序列号），新增仪器在此登记
- `<model>_setup_*.yaml` — 示波器当前配置快照（通道/时基/采集/触发）
- `<model>_waveform_*.csv` — 原始波形数据（单文件可达上百 MB）
